# ComboCloud — Cloud Kitchen Marketplace

A responsive food discovery and ordering frontend inspired by modern food-delivery marketplaces.

## Included in this first build
- Food discovery homepage with cuisine filters and search
- Sample cloud kitchens, ratings, delivery estimates and offers
- Kitchen menu views with add-to-cart actions
- Cart drawer with quantity controls and delivery-fee calculation
- Demo checkout (does not collect payment or create a real order)
- Responsive desktop and mobile layouts

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current scope
This is a frontend demo using sample data. Authentication, Supabase persistence, live delivery tracking, real payment processing, partner/admin dashboards and production order management are not connected yet.
